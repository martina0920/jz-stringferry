# J&Z 弦渡（jz_stringferry）

音乐编曲吉他学习 App · 佳宇（开发者）& 泽华（需求方）

> 一人一弦，合奏成曲。

## 技术栈

- **Flutter 3.47.5 / Dart 3.13**（安卓 + iOS 双端）
- 状态管理：`provider`
- 路由：`go_router`
- 本地存储：`sqflite`（和弦库 500+、学习计划、打卡数据）
- 网络：`dio`（AI 助手接大模型 API）
- 音频：`just_audio`（和弦试听 / 扒带播放）、`record`（扒带录音）

## 目录结构

```
lib/
├── main.dart                 # 入口
├── app.dart                  # 根组件（主题 + 路由）
├── core/
│   ├── theme/app_theme.dart  # 品牌主题（白底炭黑细线 · 香槟金强调）
│   ├── router/app_router.dart# 路由表（七大模块）
│   └── models/               # 数据模型（chord / study_task）
├── data/
│   └── chord_repository.dart # 和弦数据仓库（首版内置示例）
└── features/
    ├── home/                 # 首页（模块入口）
    ├── chord/                # 模块一：和弦查询
    ├── study/                # 模块二：学习计划
    ├── ai/                   # 模块三：AI 助手
    ├── arranger/             # 模块四：编曲工作台
    ├── cover/                # 模块五：扒带助手
    ├── toolbox/              # 模块六：吉他工具箱
    └── settings/             # 设置
```

## 运行

```bash
# 首次：拉取依赖
flutter pub get

# 运行（连接设备或模拟器）
flutter run

# 静态检查
flutter analyze

# 构建安卓 APK（需 Android SDK）
flutter build apk --debug
```

## 已确认的产品决策（需求文档 v0.3）

| 决策项 | 结论 |
|---|---|
| 目标平台 | 安卓 iOS 双端同时 |
| AI 助手 | 接现成大模型 API |
| 账号与数据 | 纯本地、无需账号 |
| 计划分析 | 完成率＋趋势＋耗时统计＋薄弱项 |
| 和弦库 | 尽量全（500+） |
| 编曲工作台 | 全部功能 |
| 扒带来源 | 本地导入＋录音 |
| 双人模式 | 先做单人版（双人共创二期） |
| 音感训练 | 完整版 |
